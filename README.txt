AI BATTLE BY FATMATILDA — структура проекта

index.html                 Главная страница сайта.
tests/index.json           Список ID тестов, которые нужно показать.
tests/fireball/data.json   Описание теста, общий промпт и статистика моделей.
tests/fireball/*.html      Файлы сайтов, созданных нейросетями.

КАК ДОБАВИТЬ НОВЫЙ ТЕСТ
1. Создай папку, например tests/neon-race/.
2. Положи в неё data.json и файлы сайтов моделей.
3. Добавь ID папки в массив tests в tests/index.json:
   { "tests": ["fireball", "neon-race"] }
4. В data.json укажи title, description, prompt и объекты моделей.

КЛЮЧИ МОДЕЛЕЙ
Используй строго такие названия ключей: deepseek, chatgpt, claude.

ПОЛЯ В data.json
- title: название теста.
- description: короткое описание теста.
- prompt: общий промпт, одинаковый для всех моделей.
- models.<ключ>.fullModel: полное название модели и режим.
- revisions: число дополнительных правок после основного промпта.
- durationSeconds: общее время в секундах.
- codeLines: количество строк кода.
- characters: количество символов кода.
- file: имя HTML-файла в этой же папке.
- note: необязательная подпись под названием модели.
- enabled: необязательно; false скрывает/отключает участие модели.

ЗАПУСК
Поскольку главная страница загружает JSON через fetch(), не открывай index.html двойным кликом через file://.
Запусти локальный сервер из папки MatildaAIContest:
  py -m http.server 8000
Затем открой в браузере:
  http://localhost:8000

На GitHub Pages сайт будет работать без дополнительного сервера.

Сайты, созданные моделями, открываются в той же вкладке браузера.
Числа и названия моделей в примере — демонстрационные. Замени их реальными результатами.
